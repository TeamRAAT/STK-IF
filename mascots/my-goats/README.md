# My goats

Put your own goat (Nilgiri tahr) pictures in this folder.

Then open `mascots/mascot-list.js` and write the picture's path next to the spot where it should appear, for example:

```js
"home-hero": "mascots/my-goats/your-picture.png",
```

Use pictures with a transparent background (.png or .webp). Full guide: `mascots/README.md`.
